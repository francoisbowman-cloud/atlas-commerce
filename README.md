# Atlas Commerce

Plataforma de comercio autónomo. Este repositorio es la fuente oficial de verdad del proyecto: documentación fundacional, RFCs versionados y la Biblia técnica/de negocio.

## Estructura

- `/RFCs/` — Registro histórico de decisiones (Request for Comments), numerados de forma secuencial (RFC-000, RFC-001, ...). Ver `RFC-001-Proceso-RFC-y-Gobernanza-Documental.docx` para el proceso completo. Los RFCs nunca se borran ni renombran una vez aceptados o rechazados.
- `/Biblia/` — Síntesis narrativa y estable del estado actual del proyecto, organizada en volúmenes temáticos (Volumen I: Filosofía y Constitución, en adelante). Se actualiza cuando un RFC aceptado cambia el estado del proyecto, citando siempre el RFC de origen.

## Documentos actuales

| Documento | Descripción |
|---|---|
| `RFCs/RFC-000-Documento-Fundacional.docx` | Visión, misión, filosofía, principios y Constitución de Atlas Commerce. |
| `RFCs/RFC-001-Proceso-RFC-y-Gobernanza-Documental.docx` | Cómo se numeran, versionan y aprueban las decisiones del proyecto. |
| `RFCs/RFC-002-Etsy-Productos-Digitales.docx` | Etsy y productos digitales como mecanismo del modelo de negocio. |
| `Biblia/Volumen-I-Filosofia-y-Constitucion.docx` | Versión narrativa estable de RFC-000 y RFC-001. |

## Control de versiones

Este repositorio usa Git para mantener un historial completo de la documentación: cada cambio queda registrado como un commit, permitiendo restaurar cualquier punto anterior y trabajar desde cualquier ordenador clonando el repositorio.
